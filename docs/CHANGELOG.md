# تغییرات 0.3.0

## بک‌اند
- پیوست‌ها دیگر باعث خطای ۴۰۰ Gemini نمی‌شوند (تبدیل به inlineData/متن).
- حفظ `thoughtSignature` در فراخوانی ابزار برای مدل‌های Gemini 3.
- Gemini OAuth: ساختار درخواست/پاسخ Code Assist اصلاح شد.
- ذخیرهٔ تنظیمات کلیدهای خالی را پاک نمی‌کرد؛ حالا فقط با تیک «فراموش کن». `mcpServers` ذخیره می‌شود و توکن‌هایش در GET پنهان است.
- `run_shell`: توقف کل گروه فرایند هنگام timeout، کد خروج ۱۲۴، نگه‌داشتن انتهای خروجی، اعتبارسنجی فرمان خالی.
- تکه‌های زندهٔ خروجی دیگر تاریخچهٔ گفتگو را از بافر بیرون نمی‌اندازند و دیسک را پر نمی‌کنند.
- شناسهٔ رویدادها یکنواخت (بدون ریست پس از پاک‌کردن/ری‌استارت).
- انتشار روی GitHub فایل‌های نقطه‌دار (`.github`, `.gitignore`) را هم می‌فرستد و `.env*` را نه؛ هشدار سقف ۲۰۰ فایل.
- ابزارهای `cloudflare_api`/`linear_api`/`hf_api`/`drive_api`/`mcp_call` پارامترهای body/variables/arguments را اعلام می‌کنند.
- فیلتر public/private مخازن GitHub کار می‌کند؛ مسیر برنامه از محل فایل محاسبه می‌شود (نه cwd)؛ محافظ Host؛ CORS مطابق PORT؛ `restart_server` با launcher واقعاً ری‌استارت می‌کند.

## رابط
- تأیید فرمان: شناسهٔ اشتباه (`approval_id`) و کارت تکراری رفع شد.
- جلوگیری از Pollهای هم‌زمان (پیام‌های تکراری).
- پیش‌نمایش زندهٔ کد بدون `allow-same-origin` (کد تولیدشده دیگر به API محلی دسترسی ندارد).

## نصب‌کننده
- `run_quiet` شکست‌ها را قورت می‌داد؛ اصلاح شد. launcher با حلقهٔ ری‌استارت.
