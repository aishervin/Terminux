# Terminux

☬SHΞN™ made a dual-core local intelligent terminal agent: Gemini provides the reasoning; Termux is the on-device terminal and tool runner.

ایجنت برنامه‌نویسی محلی برای Termux با رابط وب فارسی، Gemini و ابزارهای اختصاصی GitHub و Cloudflare. هیچ سرور واسطی ندارد؛ برنامه و رابط روی گوشی اجرا می‌شوند و درخواست‌ها مستقیماً به APIهای رسمی می‌روند.

## نصب با یک فرمان

Termux را از [F-Droid](https://f-droid.org/packages/com.termux/) یا صفحهٔ [GitHub رسمی Termux](https://github.com/termux/termux-app/releases) نصب و باز کن، سپس این فرمان را در Termux اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/aishervin/Terminux/main/install.sh | bash
```

نصب‌گر Python و ابزارهای لازم را نصب می‌کند، پروژه را دریافت می‌کند، ایجنت را اجرا می‌کند و صفحهٔ محلی را در مرورگر باز می‌کند. در تنظیمات صفحه، کلید Gemini و در صورت نیاز توکن GitHub و Cloudflare را وارد کن؛ قالب‌های جدید `AQ.` و قالب‌های قدیمی کلید پذیرفته می‌شوند. برای ساخت کلید Gemini به [Google AI Studio](https://aistudio.google.com/app/apikey) برو. استفاده از Gemini API تابع سهمیه و قیمت‌گذاری Google است.

برای توقف، به Termux برگرد و `Ctrl+C` بزن. اجرای دوبارهٔ فرمان نصب، نسخهٔ تازه را دریافت می‌کند و تنظیمات کاربر را نگه می‌دارد.

## معماری

```text
مرورگر Android ⇄ localhost ⇄ Terminux در Termux
                               ├─ HTTPS → Gemini API
                               ├─ HTTPS → GitHub REST API
                               └─ HTTPS → Cloudflare API
```

فضای کاری پروژه‌ها: `~/Terminux-workspace`. تاریخچه و نوبت‌های گفتگو در `~/.config/terminux/history.json` و `events.json` نگه‌داری می‌شوند و پس از بستن/بازکردن ایجنت هم باقی می‌مانند. تنظیمات و توکن‌ها در `~/.config/terminux/config.json` ذخیره می‌شوند.

## استفاده

- ابزارهای محلی: اجرای فرمان در پوشهٔ پروژه، فهرست‌کردن/خواندن/نوشتن فایل‌ها، اجرای build و test.
- با دکمهٔ پیوست، حداکثر ۵ فایل، هرکدام تا ۲ مگابایت، انتخاب کن. متن فایل‌های متنی و تصویر/PDF به Gemini می‌رسد؛ همهٔ فایل‌های آپلودشده در `~/Terminux-workspace/.terminux-uploads` می‌مانند و می‌توان آن‌ها را از مرورگر فایل دید یا دانلود کرد.
- فرمان‌های build/test خروجی کامل قابل‌پیمایش دارند و لاگشان را می‌توان کپی یا دانلود کرد. Enter در کادر پیام خط جدید می‌سازد؛ فقط دکمهٔ ارسال پیام را می‌فرستد.
- ابزار GitHub: ساخت مخزن، خواندن API و انتشار یک پروژهٔ محلی به‌صورت یک commit.
- ابزار Cloudflare: دسترسی مستقیم به APIهای حساب، zone، DNS و Workers که توکن اجازه‌شان را می‌دهد.
- در حالت پیش‌فرض، اجرای فرمان، نوشتن فایل و هر تغییر GitHub/Cloudflare در مرورگر تأیید می‌خواهد؛ درخواست‌های فقط‌خواندنی API تأیید نمی‌خواهند.
- گزینهٔ «اجرای خودکار عملیات» این تأییدها را تا پایان همان اجرای Terminux خاموش می‌کند.
- فرمان‌ها در `~/Terminux-workspace` و با دسترسی کاربر Termux اجرا می‌شوند. دسترسی root ایجاد نمی‌شود.
- مدل پیش‌فرض `gemini-2.5-flash` است و نام مدل را می‌توان از تنظیمات تغییر داد.
- برای ساخت مخزن، نام و عمومی/خصوصی بودن را بگو. برای انتشار، ایجنت فایل‌های پوشهٔ پروژه را در مخزن commit می‌کند.
- انتشار GitHub در این نسخه حداکثر ۲۵۰ فایل و ۵ مگابایت است؛ فایل‌های متنی و assetهای باینری معمولی پشتیبانی می‌شوند. `.git`، `.venv`، `node_modules`، `vendor`، `.terminux-uploads`، فایل‌های bytecode، `.env` و `.env.*` (به‌جز `.env.example`)، کلیدها و فایل‌های credential شناخته‌شده منتشر نمی‌شوند. فایل‌های حذف‌شده از پوشه به‌طور خودکار از مخزن حذف نمی‌شوند.
- ابزار shell به `gh` یا `wrangler` نیاز ندارد؛ ایجنت APIهای GitHub و Cloudflare را با توکن ذخیره‌شده فراخوانی می‌کند. به‌طور پیش‌فرض توکن به prompt، خروجی API یا متغیرهای shell اضافه نمی‌شود.
- اگر گزینهٔ «در دسترس قراردادن توکن‌ها برای فرمان‌های gh و wrangler» را روشن کنی، `GH_TOKEN`، `GITHUB_TOKEN` و `CLOUDFLARE_API_TOKEN` فقط به پردازش‌های shell ایجنت داده می‌شوند. چاپ این مقادیر توسط یک فرمان می‌تواند آن‌ها را در خروجی ارسالی به Gemini قرار دهد.

## محدودیت‌ها و حریم خصوصی

- سرویس فقط روی `127.0.0.1` گوش می‌دهد و رابط آن از دستگاه‌های دیگر شبکه در دسترس نیست.
- متن گفتگو، فایل‌های متنی/تصویر/PDF پیوست‌شده، محتوای فایل‌هایی که مدل می‌خواند و خروجی ابزارها برای پاسخ‌سازی به Gemini فرستاده می‌شوند. کلید Gemini برای احراز درخواست به Google می‌رود.
- توکن‌های GitHub و Cloudflare در مسیر عادی فقط در header درخواست به میزبان رسمی همان سرویس قرار می‌گیرند. فایل تنظیمات با مجوز محدود کاربر (`0600`) ذخیره می‌شود، اما رمزنگاری مستقل ندارد.
- GitHub token باید مجوز ساخت مخزن و دسترسی لازم به Contents داشته باشد. مجوز Cloudflare را متناسب با کار موردنظر، مانند DNS یا Workers، انتخاب کن.
- گزینهٔ اجرای خودکار عملیات، فرمان‌ها و تغییرات API را بدون تأیید اجرا می‌کند. دسترسی توکن‌ها همواره تابع permission خود آن توکن است.
- فرمان‌ها sandbox نشده‌اند و با دسترسی خود Termux اجرا می‌شوند؛ shell می‌تواند به فایل تنظیمات محلی نیز دسترسی پیدا کند. تأیید دستی را روشن نگه دار، مگر اینکه عمداً اجرای خودکار را بخواهی.
- Android ممکن است فرایند Termux را در پس‌زمینه متوقف کند. این نسخه هنگام اجرا در پیش‌زمینهٔ Termux کار می‌کند؛ اجرای دائمی پس‌زمینه یا شروع خودکار پس از راه‌اندازی گوشی هنوز پشتیبانی نمی‌شود.
- ابزارهای تعاملی که به TTY واقعی نیاز دارند ممکن است کار نکنند؛ این نسخه برای فرمان‌هایی طراحی شده که با ورودی/خروجی معمولی اجرا می‌شوند.
- «فارسی‌کردن Termux» فقط تا جایی ممکن است که خود Android، پوسته یا برنامهٔ موردنظر از زبان فارسی پشتیبانی کند.

## اجرای دستی و توسعه

نیازمندی‌ها: Python 3.10 یا جدیدتر. پروژه هیچ وابستگی Python خارجی ندارد.

```bash
python app.py --open-browser
```

یا مرورگر را دستی به `http://127.0.0.1:8765` ببر. برای اجرای آزمون‌ها:

```bash
python -m unittest discover -s tests -v
```
