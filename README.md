# Terminux

☬SHΞN™ made a dual-core local intelligent terminal agent: Gemini provides the reasoning; Termux is the on-device terminal and tool runner.

ایجنت ترمینال محلی برای Termux با رابط وب فارسی و Gemini. سرور واسطی لازم نیست: برنامه و رابط وب روی خود گوشی اجرا می‌شوند؛ فقط درخواست مدل از گوشی مستقیماً به Google Gemini API می‌رود.

## نصب با یک فرمان

Termux را از [F-Droid](https://f-droid.org/packages/com.termux/) یا صفحهٔ [GitHub رسمی Termux](https://github.com/termux/termux-app/releases) نصب و باز کن، سپس این فرمان را در Termux اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/aishervin/Terminux/main/install.sh | bash
```

نصب‌گر Python و ابزارهای لازم را نصب می‌کند، پروژه را دریافت می‌کند، ایجنت را اجرا می‌کند و صفحهٔ محلی را در مرورگر باز می‌کند. بار اول، کلید Gemini API را در تنظیمات صفحه وارد کن. برای ساخت کلید به [Google AI Studio](https://aistudio.google.com/app/apikey) برو. استفاده از Gemini API تابع سهمیه و قیمت‌گذاری Google است.

برای توقف، به Termux برگرد و `Ctrl+C` بزن. اجرای دوبارهٔ فرمان نصب، نسخهٔ تازه را دریافت می‌کند و تنظیمات کاربر را نگه می‌دارد.

## معماری

```text
مرورگر اندروید
    ↕ HTTP محلی / 127.0.0.1:8765
app.py در Termux
    ↕ HTTPS مستقیم
Google Gemini API
```

Termux میزبان رابط وب و حلقهٔ ابزار است. Gemini می‌تواند ابزار `run_shell` را درخواست کند؛ برنامهٔ Termux فرمان را اجرا می‌کند و کد خروج و خروجی واقعی را به مدل بازمی‌گرداند. تاریخچهٔ گفتگو در حافظهٔ فرایند می‌ماند و با بستن برنامه پاک می‌شود. API key در `~/.config/terminux/config.json` ذخیره می‌شود.

## استفاده

- در حالت پیش‌فرض، هر فرمان پیشنهادی Gemini در مرورگر نمایش داده می‌شود و باید آن را تأیید یا رد کنی.
- گزینهٔ «اجرای خودکار فرمان‌ها» تأیید هر فرمان را خاموش می‌کند و تا پایان اجرای برنامه فعال می‌ماند.
- فرمان‌ها با دسترسی کاربر Termux در پوشهٔ خانه اجرا می‌شوند. دسترسی root ایجاد نمی‌شود.
- مدل پیش‌فرض `gemini-2.5-flash` است و نام مدل را می‌توان از تنظیمات تغییر داد.
- برای دیدن خروجی فرمان، کارت خروجی را باز کن. خطاها و کد خروج هم به مدل فرستاده می‌شوند تا بتواند ادامه دهد.

## محدودیت‌ها و حریم خصوصی

- سرویس فقط روی `127.0.0.1` گوش می‌دهد و رابط آن از دستگاه‌های دیگر شبکه در دسترس نیست.
- متن گفتگو و خروجی ترمینال برای پاسخ‌سازی به Google Gemini API فرستاده می‌شوند. API key نیز نزد Google برای احراز درخواست استفاده می‌شود.
- فرمان‌ها sandbox نشده‌اند و با دسترسی خود Termux اجرا می‌شوند. تأیید دستی را روشن نگه دار، مگر اینکه عمداً اجرای خودکار را بخواهی.
- Android ممکن است فرایند Termux را در پس‌زمینه متوقف کند. این نسخه هنگام اجرا در پیش‌زمینهٔ Termux کار می‌کند؛ اجرای دائمی پس‌زمینه یا شروع خودکار پس از راه‌اندازی گوشی هنوز پشتیبانی نمی‌شود.
- ابزارهای تعاملی که به TTY واقعی نیاز دارند ممکن است کار نکنند؛ این نسخه برای فرمان‌هایی طراحی شده که با ورودی/خروجی معمولی اجرا می‌شوند.
- «فارسی‌کردن Termux» فقط تا جایی ممکن است که خود Android، پوسته یا برنامهٔ موردنظر از زبان فارسی پشتیبانی کند.

## اجرای دستی و توسعه

نیازمندی‌ها: Python 3.10 یا جدیدتر. پروژه هیچ وابستگی Python خارجی ندارد.

```bash
python app.py --open-browser
```

یا مرورگر را دستی به `http://127.0.0.1:8765` ببر. برای اجرای آزمون‌ها:

```bash
python -m unittest discover -s tests -v
```
